Cómo se mide
  • Cada cinco minutos se hace una petición GET a la URL del servicio. Se considera operativo cuando devuelve HTTP 2xx y contiene el marcador esperado.
  • Errores del servidor, de conexión o tiempos de espera cuentan como fallo. Si la sonda no puede resolver el dominio, la comprobación queda sin confirmar. Solo las comprobaciones concluyentes entran en el porcentaje.
  • El uptime histórico divide las comprobaciones operativas entre el total de concluyentes desde la primera medición. Los totales de cada web y el global suman las mediciones de sus servicios.
  • Las barras cubren los últimos 30 días en hora peninsular. El amarillo indica fallos. El rojo indica que un mismo servicio acumuló más de tres horas seguidas entre comprobaciones fallidas. Si la caída cruza medianoche, se marcan ambos días.
  • El estado actual pasa a «sin confirmar» si la última comprobación no fue concluyente o está desactualizada.
  • Las sondas consultan directamente las webs y APIs de cada organismo. Catálogo de Reforma Digital.
